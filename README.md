# 햇살농장

모바일 브라우저에서 바로 즐기는 농장 경영 시뮬레이션 게임입니다. 설치가 필요 없습니다.

- 실행: `farm/index.html`을 휴대폰 브라우저로 열기 (GitHub Pages 등에 올리면 링크로 플레이 가능)
- 소스: `farm/game.html` 수정 후 `farm/build.sh` 실행 → `farm/index.html` 생성

## 게임 방법
- **밭**: 빈 밭을 누르면 고른 씨앗을 심고, 자라는 밭을 누르면 물을 줘요 (1.5배 빨리 자람). 다 자라면 눌러서 수확.
- **축사**: 레벨 2부터 닭, 4부터 젖소, 6부터 양. 사료를 먹고 달걀·우유·양털을 만들어요.
- **시장**: 가격이 매일 바뀌어요. 오른 날 파세요. 퇴비장·스프링클러로 농장을 개선할 수 있어요.
- **주문**: 이웃 주문을 채우면 시장보다 비싸게 팔고 경험치도 받아요.
- 하루는 2분, 비 오는 날은 밭이 저절로 젖어요. 게임을 꺼 둔 동안에도 최대 8시간까지 농장이 자라요. 진행 상황은 브라우저에 자동 저장돼요.
