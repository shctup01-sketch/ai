# 햇살농장

모바일 브라우저에서 바로 즐기는 농장 경영 시뮬레이션 게임입니다. 설치가 필요 없습니다.

- 실행: `farm/index.html`을 휴대폰 브라우저로 열기 (GitHub Pages 등에 올리면 링크로 플레이 가능)
- 소스: `farm/game.html` 수정 후 `farm/build.sh` 실행 → `farm/index.html` 생성

## 게임 방법
- **밭**: 빈 밭을 누르면 고른 씨앗을 심고, 자라는 밭을 누르면 물을 줘요 (1.5배 빨리 자람). 다 자라면 눌러서 수확.
- **축사**: 레벨 2부터 닭, 4부터 젖소, 6부터 양. 사료를 먹고 달걀·우유·양털을 만들어요.
- **시장**: 가격이 매일 바뀌어요. 오른 날 파세요. 퇴비장·스프링클러로 농장을 개선할 수 있어요.
- **주문**: 이웃 주문을 채우면 시장보다 비싸게 팔고 경험치도 받아요.
- 하루는 2분, 비 오는 날은 밭이 저절로 젖어요. 게임을 꺼 둔 동안에도 최대 8시간까지 농장이 자라요. 진행 상황은 브라우저에 자동 저장돼요.

# 흙속왕국 (개미 군집 육성 + 1:1 대전)

- 실행: `ant/index.html` · 소스: `ant/game.html` → `ant/build.sh`
- **군집 탭 (파밍):** 여왕이 낳을 개미만 고르면 나머지는 개미 습성대로 자동으로 움직여요. 페로몬 길, 경로 적분, 경보와 집단 공격, 장례, 나이에 따른 역할 분담, 알→애벌레→고치→성충. 게임을 꺼 둬도 최대 6시간까지 먹이를 모아요. 사냥감을 잡으면 꿀과 개미 표본이 나와요.
- **대전 탭:** 컴퓨터 군집과 4분짜리 1:1. 일개미로 시작해 먹이를 모으고, 덱의 개미를 낳아 상대 여왕을 쓰러뜨려요. 전투개미는 3마리가 모이면 습격대를 꾸려 출발해요. 리그는 흙먼지부터 개미왕국까지 7단계이고, 승급하면 새 종이 열려요. 이기면 알집을 받아요.
- **도감 탭:** 실제 개미 12종 (불개미의 독, 곰개미의 개미산, 군대개미 떼, 덫턱개미의 턱, 꿀단지개미, 사무라이개미의 노예사냥, 총알개미의 침 등). 표본과 꿀로 Lv10까지 강화해요.
- **성장 탭:** 일일 임무 4개와 완료 보너스, 굴 강화 (저장고, 육아실, 여왕방 → 대전 시작 먹이, 부화 속도, 여왕 체력).
- 진행 상황은 브라우저에 자동 저장돼요.
