# 햇살농장

모바일 브라우저에서 바로 즐기는 농장 경영 시뮬레이션 게임입니다. 설치가 필요 없습니다.

- 실행: `farm/index.html`을 휴대폰 브라우저로 열기 (GitHub Pages 등에 올리면 링크로 플레이 가능)
- 소스: `farm/game.html` 수정 후 `farm/build.sh` 실행 → `farm/index.html` 생성

## 게임 방법
- **밭**: 빈 밭을 누르면 고른 씨앗을 심고, 자라는 밭을 누르면 물을 줘요 (1.5배 빨리 자람). 다 자라면 눌러서 수확.
- **축사**: 레벨 2부터 닭, 4부터 젖소, 6부터 양. 사료를 먹고 달걀·우유·양털을 만들어요.
- **시장**: 가격이 매일 바뀌어요. 오른 날 파세요. 퇴비장·스프링클러로 농장을 개선할 수 있어요.
- **주문**: 이웃 주문을 채우면 시장보다 비싸게 팔고 경험치도 받아요.
- 하루는 2분, 비 오는 날은 밭이 저절로 젖어요. 게임을 꺼 둔 동안에도 최대 8시간까지 농장이 자라요. 진행 상황은 브라우저에 자동 저장돼요.

# 흙속왕국 (개미 군집 육성 + 1:1 대전)

- 실행: `ant/index.html` · 소스: `ant/game.html` → `ant/build.sh`
- **군집 탭 (파밍):** 도감에서 발견한 모든 종을 군집에서도 키울 수 있고, 강화하면 군집 개미도 같이 강해져요. 정찰개미는 지도 밖을 탐험해 새 터(9종: 먹이·안전·육아 조건과 특수 효과가 다름)를 찾아오고, 군집은 알과 애벌레를 옮기며 이사할 수 있어요.
- **야생과 성장:** 야생 단계(1~10)를 올리면 왕지네·사마귀·장수말벌 같은 강한 적이 나오고, 키틴·독샘·로열젤리를 더 많이 얻어요. 재료로 진화 연구(큰턱·외골격·다리·페로몬·육아)를 해서 군집 개미를 강하게 만들어요.
- **계급:** 개미마다 적을 잡으면 경험치가 쌓여 이등병→원사로 진급하고 강해져요. 죽으면 사라지고, 병장 이상은 명예의 전당에 남아요. 정예 일개미는 빠르고 두 배를 나르지만 로열젤리가 필요해요.
- **굴과 야생:** 땅 위/같이/땅속 화면 전환. 일개미가 흙을 날라 새 방(병정 막사·버섯 정원·제2 육아실·꿀단지 방·깊은 저장고)을 파요. 굴 안에서 먹이 나누기, 여왕 시중, 부상병 회복. 땅 위에는 낮과 밤, 비, 새의 습격, 사냥감, 보스 체력바.
- **소리:** 배경음악(군집/대전), 바람·새·귀뚜라미·빗소리, 각종 효과음. 모두 코드로 합성.
- **군집 기본:** 여왕이 낳을 개미만 고르면 나머지는 개미 습성대로 자동으로 움직여요. 페로몬 길, 경로 적분, 경보와 집단 공격, 장례, 나이에 따른 역할 분담, 알→애벌레→고치→성충. 게임을 꺼 둬도 최대 6시간까지 먹이를 모아요. 사냥감을 잡으면 꿀과 개미 표본이 나와요.
- **대전 탭:** 컴퓨터 군집과 4분짜리 1:1. 일개미로 시작해 먹이를 모으고, 덱의 개미를 낳아 상대 여왕을 쓰러뜨려요. 전투개미는 3마리가 모이면 습격대를 꾸려 출발해요. 리그는 흙먼지부터 개미왕국까지 7단계이고, 승급하면 새 종이 열려요. 이기면 알집을 받아요.
- **도감 탭:** 실제 개미 12종 (불개미의 독, 곰개미의 개미산, 군대개미 떼, 덫턱개미의 턱, 꿀단지개미, 사무라이개미의 노예사냥, 총알개미의 침 등). 표본과 꿀로 Lv10까지 강화해요.
- **성장 탭:** 일일 임무 4개와 완료 보너스, 굴 강화 (저장고, 육아실, 여왕방 → 대전 시작 먹이, 부화 속도, 여왕 체력).
- 진행 상황은 브라우저에 자동 저장돼요.

# 공룡 상단 (가제, 1단계 시제품)

공룡이 되살아나 멸망한 세계에서 공룡을 길들여 상단을 꾸리고, 구역을 오가며 사냥하고 장사하는 게임. 거상식 장사와 용병 구조를 새 세계관으로 만든 오리지널 설계예요.

- 실행: `dino/index.html` (모델을 불러오므로 `python3 -m http.server`처럼 웹 서버로 열어야 해요) · 소스: `dino/game.html` → `dino/build.sh`
- 그래픽: three.js 3D, 공룡 모델은 Quaternius의 CC0 로우폴리 팩(`dino/models`, 상업 이용 가능)
- 구역 3곳(잿빛 평원·무너진 도시·썩은 늪지): 구역마다 시세, 고용 대원, 길들일 공룡, 사냥터, 우두머리가 달라요. 나라·속성 개념은 없어요.
- 무역: 사면 값이 오르고 팔면 떨어지며 매일 시세와 사건이 바뀌어요. 짐칸은 대원과 공룡 수로 정해져요.
- 이동: 지도에서 출발하면 길에서 습격이나 발견이 생겨요. 습격에 지면 짐을 잃어요.
- 전투: 대장 포함 12명 진형, 실시간 자동 전투, 적을 눌러 집중 공격. 도발 탱커, 장갑 깎기, 기절(큰 적 면역), 회복, 포탑. 전투 화면이 싸움을 따라가며 확대돼요.
- 성장 시스템: 공방 생산(육포·가죽 갑옷·탄약·강철 무기·치료약·마취 다트, 자리를 비워도 진행), 무기·방어구 3단계 강화, Lv10/Lv20 전직·성장, 상단 레벨과 스킬 5종, 구역별 의뢰 게시판, 희귀종 8종과 공룡 도감.
- 3D 지도: 세 구역과 정착지, 길, 실제 대원 구성으로 걸어가는 상단.
- 포획: 체력 30% 이하 공룡에게 마취 다트. 전투 경험치로 레벨업, 여관에서 회복.

## pixel/ — 공룡 상단 (픽셀 월드)

`dino/`의 무역·전투·장비 시스템을 그대로 쓰되, 화면을 픽셀 그래픽의 큰 월드로 다시 만든 버전입니다.

- 하나로 이어진 큰 맵(구역 7곳, 사냥터 35곳, 야생 레벨 1~50)을 직접 걸어 다닙니다. 가로·세로 화면 모두 지원합니다.
- 공룡 무리가 필드에 보이고, 누르면 그 자리에서 실시간 전투가 벌어집니다.
- 3D 모델을 실행 중에 작은 픽셀 스프라이트로 구워서 2D로 그립니다.
- 포만감, 전장(예금·이자), 마을 투자와 배당(대방), 여각 창고, 진형, 길에서 만나는 상단과의 거래가 있습니다.
- 다른 상단은 컴퓨터가 움직이는 가상의 상단입니다. 실제 온라인 기능은 없습니다.

`pixel/build.sh`로 `index.html`을 만들고, `pixel/models`는 `dino/models`를 가리킵니다.
